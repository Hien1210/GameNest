Thư mục này lưu ảnh bìa game dùng cho hiệu ứng Marquee (nền cuộn ngang) ở
Hero section của trang chủ (index.jsp).

Định dạng: .png
Quy ước đặt tên: PascalCase, không dấu cách (ví dụ: BlackMythWukong.png)

Danh sách ảnh đang dùng (khai báo trong index.jsp, mục <script> ở cuối file):
  Row 1: Cs2, Valorant, Minecraft, GTA5, FcOnline, PUBG, ApexLegends
  Row 2: Fortnite, DeltaForce, Battlefield2042, CallOfDutyWarzone, ZenlessZoneZero, Efootball, ArenaBreakout
  Row 3: BlackMythWukong, ForzaHorizon6, Battlefield6, ReadyOrNot, Bloodstrike, FcMobile, Roblox

Muốn thêm/đổi ảnh: bỏ file .png vào thư mục này, rồi cập nhật mảng "rows"
trong phần <script> cuối file index.jsp cho khớp tên file.

Độ phân giải khuyến nghị: tối thiểu 440x260 (ảnh hiển thị dạng thumbnail
220x130, x2 cho màn hình retina) để không bị vỡ nét.
